Comment l'utiliser
Authentifie chaque requête avec le header Authorization: Bearer cmp_…
Endpoints disponibles
GET/api/v1/health
POST/api/v1/images/upload
GET/api/v1/batches/<id>
GET/api/v1/images?fit=high&limit=20
GET/api/v1/images/<filename>
POST/api/v1/images/<filename>/reindex
Exemple curl (upload + indexation)
curl -X POST http://localhost:5000/api/v1/images/upload \
  -H "Authorization: Bearer cmp_TA_CLE" \
  -F "files=@photo1.jpg" \
  -F "files=@photo2.png"
Exemple Python
import requests
KEY = "cmp_TA_CLE"
r = requests.post(
    "http://localhost:5000/api/v1/images/upload",
    headers={"Authorization": f"Bearer {KEY}"},
    files=[("files", open("photo.jpg", "rb"))],
)
print(r.json())  # {"ok": true, "saved": [...], "batch_id": 7, ...}
